# ⚠️ ARCHIVED — GIT REPOSITORY AS A BUNDLE

This git repository is now archived as a git bundle, because the history is contaminated with private data.

## Background

- The git history contains private data and cannot be safely shared or published.
- Cleaning up the history afterwards is not reliably possible and is not intended.
- Therefore the full repository, including its history, is exported into a git bundle and kept offline only.

## Consequences

- Distribution and publication are NOT intended.
- The repository will NOT be pushed to any public or shared remote.
- The bundle must be treated as contaminated and stored with restricted access.
